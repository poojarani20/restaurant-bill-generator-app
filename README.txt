# Restaurant Bill Generator

Files:
- index.html
- style.css
- script.js

Features:
- Responsive layout matching the supplied restaurant-bill screenshot
- Live restaurant details / invoice preview
- Add and remove multiple items
- Automatic subtotal, CGST/SGST and grand total calculation
- Payment method selection
- Optional field show/hide
- GST/FSSAI fields
- Currency selection
- Logo upload and logo URL
- Template 1 / Template 2 switch
- Preview fullscreen button
- Download PDF button using html2canvas + jsPDF CDN

Run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Enter bill data.
4. Click Download PDF.

Note: PDF generation uses CDN libraries, so an internet connection is recommended when opening the page.
